# API Introduction

## 1. Purpose
The BOMS API enables external applications to access and manage business information through standardized HTTP requests.

## 2. API Architecture
The API follows REST (Representational State Transfer) architecture.

REST APIs allow applications to communicate through HTTP requests and responses.

## 3. Supported Data Format
The API uses JSON (JavaScript Object Notation) to exchange data.

## 4. HTTP Methods

| Method | Description |
|---|---|
| GET | Retrieves information |
| POST | Creates a new record |
| PUT | Replaces an existing record |
| PATCH | Updates selected fields |
| DELETE | Removes a record |

## 5. API Versioning
The API uses version numbers in its URL.
Example:
https://api.boms-demo.com/v1
