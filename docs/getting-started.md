# Getting Started

## Prerequisites

Before using the BOMS API, ensure you have:

- An API access token
- An internet connection
- An API testing tool such as Postman
- Basic knowledge of HTTP and JSON

## Base URL

All API requests use the following base URL:

https://api.boms-demo.com/v1

## Making Your First API Request

To retrieve a list of employees, send a GET request.

GET /employees

Complete URL:
https://api.boms-demo.com/v1/employees

## Expected Result

A successful request returns employee records in JSON format.

Note: This is a demonstration API. The example
endpoint is not connected to a live server.
